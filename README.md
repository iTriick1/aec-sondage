# aec-sondage

Page de vote **sur téléphone** pour le quiz en direct de la présentation étudiante de l'AEC en intelligence
artificielle.

- La salle scanne un code QR affiché à l'écran, qui ouvre cette page avec le nom du canal (`?t=...`).
- Les questions et les votes passent par [ntfy.sh](https://ntfy.sh) (service public gratuit, sans compte).
- Le vote est anonyme : un identifiant aléatoire par téléphone, aucune donnée personnelle.
- L'écran de présentation (dépôt privé de la classe) compte les votes et anime les résultats.

Publié avec GitHub Pages.
